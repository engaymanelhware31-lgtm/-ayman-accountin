# Ayman Accounting
نسخة تجريبية 1.2 من نظام محاسبي عربي.

## التشغيل
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى المستودع.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر Branch: main والمجلد: / (root).
4. احفظ وانتظر رابط GitHub Pages.

> هذه النسخة Prototype للتجربة. التخزين الحالي محلي في المتصفح (localStorage)، وليست قاعدة بيانات مشتركة بين المستخدمين.
